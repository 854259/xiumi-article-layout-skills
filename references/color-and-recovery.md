# 秀米配色与连接恢复：实际案例

以下内容整理已验证的界面现象与处理方法。当前页面样式和控件作为操作依据，来源及验证记录在相应任务记录中维护。

## 1. 区分超时、目标失效与网址安全停止

先读取原始工具返回，确认是否包含停止或接管要求，再按错误类型处理。同一调用同时出现超时与明确停止要求时，优先执行停止要求。

| 类型与证据 | 当次处理 | 恢复后核验 |
|---|---|---|
| 普通超时或慢响应；返回未要求安全停止 | 在当前工具允许范围内，沿已选浏览器路径先读状态，判断动作是否已生效；运行时确已重置时按当前文档重新初始化并绑定目标 | 实际内容、选区及保存状态，避免重复执行已生效动作 |
| 陈旧标签，例如`No tab with id`；已选浏览器连接仍有效 | 在同一浏览器连接用当前文档支持的`listTabs`取得实时清单，只重新绑定失效标签 | 精确标签、准确URL、标题及稿件内容均对应目标 |
| 同一URL出现多个匹配 | 在当前清单中区分浏览器实例、编辑稿、预览稿与重复标签，再按精确目标绑定 | URL相同也继续核对标题和实际内容 |
| 工具明确表示无法高置信确认当前网址，并要求停止本轮或用户接管 | 立即按当次返回结束界面操作，记录已完成位置和停止原因，按要求交接 | 后续操作继续服从原停止条件及当前工具文档和返回；工具允许后重新核验有效目标，才恢复编辑 |

**普通故障的优先路径：** 已选浏览器连接可用时，保持该浏览器路径，先处理具体失效目标。慢调用本身不足以判定需要改走原生窗口控制。只有当前工具允许并且实际证据表明旧标签失效、目标页面也不在实时清单中时，才按文档在同一有效连接打开已确认的编辑URL。常规恢复步骤仅适用于工具允许继续的情况；明确停止后，不通过更换入口、窗口或控制技术规避要求。

**已验证的恢复范围：** 跨三天的本地原始日志显示，原生窗口读取路径多次返回无法确认当前网址的同类安全停止；同一已选浏览器的标签路径在多次后续调用中，成功返回准确URL、标题及页面内容。这些证据说明两条控制路径的实际结果不同，底层网址识别机制的故障仍未定位。其中一次事件先发生普通合批超时与运行时重置，随后原生窗口读取另行返回安全停止，两种返回分别记录；后续有效标签绑定及单步检索恢复成功，该次恢复没有重启或重装软件、修改网络或更改安全规则。另一次旧标签不存在时，同一有效浏览器中的实时标签清单提供了新目标，核对同一稿件后重绑成功。可确认的是恢复了有效目标绑定，不据此声称修复了底层识别机制，也不按底层报错条数推定用户所说的事件次数。新用户消息或URL只提供目标线索，不自动解除停止要求；每次继续仍由原停止条件和当次工具允许范围决定。

**高延迟调用的安排：** 在单个慢原语约21秒的已观察连接中，以单动作或单检查起步；需要合批时先控制为总计两个慢原语，再按实测调整。两个动作加一次检查共三个慢原语，约63秒，可能超过60秒调用窗口。耗时是该次观测参考值，不是时限保证。普通超时后先核对是否生效，再决定重试；把已确认的恢复动作、结果和未查明原因分开记录。账号登录及人工接管按当前页面提示办理。

## 2. 选中背景层，区分正文输入态与布局态

**现象：** 点击渐变卡片中心仍出现“字体/字号”工具栏，改色落到了正文或内部文本块。

**已验证步骤：**

1. 用当前工具支持的 Escape 退出文字输入态。
2. 重新读取截图或渲染边界；页面可能已滚动。
3. 点击目标容器露出的边缘，封面可选择照片之外的背景区域。
4. 确认工具栏包含布局、宽度、布局样式、背景色、边距、边框或阴影等对应控件。
5. 选中目标背景色入口，修改后查看整块背景与文字。

**已排查的尝试：** “组件定位”在该页面打开的是位置设置；切换外层布局的成功路径是退出正文态后重新点容器边缘。下次先确认工具栏和选中边框，再操作颜色。

## 3. 调色板中同色重复、属性含换行

**现象：** 看起来相同的颜色标题在精确定位时匹配为零；页面色与个人色中存在同色。

**已验证：** 当前DOM中颜色提示属性含换行，访问性文字显示为空格。通过受支持的只读页面检查取得实际属性，在已确认的调色板区域按色值片段定位，并核对唯一目标。

**优化：** 常规控件优先按可见文字和角色操作；遇到重复匹配时限定当前弹层、页面颜色或个人颜色区域。具体选择器、属性和颜色值由当前页面提供。

## 4. 按角色改色，分别处理纯色、渐变与描边

**现象：** “全文替换”后部分灰色装饰已更新，分节背景和空心标题仍保留原色。

**已验证：** 纯色、`background-image`渐变、边框与`text-shadow`分别承担样式；纯色替换只覆盖了该操作实际支持的部分。分别检查可见样式和渲染结果，再逐类处理。

**配色示例：** 深蓝 `#245B83` 用于封面、标题描边及强调线；淡蓝 `#C8DEED` 用于边框与内容卡片；浅蓝白 `#EFF6FB` 用于背景；原正文深灰继续承担正文阅读。该组合仅作色值配置示例；实际配色根据主题、照片、文字对比和用户反馈确定。

**全文替换的适用判断：** 先核对旧色到新色映射及全部使用位置。相同颜色在正文、封面、边框中承担不同角色时，按组件分别修改。保存前逐项清点原装饰色是否仍存在。

## 5. 修改线性渐变与径向渐变

**现象：** 替换纯色后，卡片叠加了新背景色，原灰色渐变仍显示。

**已验证步骤：** 选外层布局 → 对应背景色 → 添加颜色入口 → 渐变色 → 在界面提供的渐变代码输入框填写完整值 → “应用颜色” → 回读实际背景图像样式。

保留当前卡片方向与色标位置，再修改颜色。输入值示例：

```css
linear-gradient(90deg, rgb(36, 91, 131) 7%, rgb(239, 246, 251) 76%)
radial-gradient(circle, rgb(239, 246, 251) 0%, rgba(239, 246, 251, 0) 70%)
```

同类分节背景分别选中后应用新渐变；已加入个人调色板的渐变可复用。该操作中渐变的全文替换入口未提供，逐组件应用已实际成功。

**适用边界：** 示例数值用于说明输入格式。新模板优先保留当前渐变结构，根据实际方向、色标和透明度修改。CSS值通过秀米可见的输入控件提交，页面检查使用受支持的只读方式。

## 6. 同步空心标题的多层描边

**现象：** 标题外观由多层文字阴影组成，单改一层留下混色轮廓。

**已验证步骤：** 选中对应标题文字 → 文字颜色旁的扩展入口 → “文字阴影” → 将第一层颜色设为目标色 → 退出调色板回到阴影设置 → 第一层“向后应用颜色” → 回读全部层的颜色。

全部层的颜色已更新，原偏移量和模糊值保持。“格式”菜单在该页面承担缩进等文字格式功能；阴影入口位于文字颜色的扩展控件。调色板退出后检查面板名称，再操作下一项。

**优化：** 先确认标题是填色、边框还是多层阴影，选择对应方式。层数与参数以本次标题为准。

## 7. 保存后证明改动范围

**已验证方法：** 修改前记录目标正文及图片有序列表；保存后重新打开同一编辑稿，核对新样式、全文与图片顺序。已验证的方法分别检查正文内容、图片来源与顺序、旧色替换情况，以及渐变和多层描边的保存结果。

**适用边界：** 去空白比较用于该次颜色调整的文字内容检查；对文本、换行或格式本身的修订，采用对应的逐段与样式核对。局部配色任务保留原字号、行高和图片结构，全文格式重排再应用当前指定基线。

**优化：** 将文字、图片、样式、保存状态和视觉检查分开记录；组件选择被保存动作清除后，从当前页面重新选取目标。

## 8. 预览弹层空白时使用实际阅读入口

**现象：** 编辑器“预览”弹层出现二维码，但内嵌阅读区域为空白；重复编辑标签仍显示原编辑页。

**已验证：** 通过当前可见预览框的渲染属性（如当前iframe的src）读取其实际阅读地址，在同一浏览器连接中打开独立阅读页，核对本篇标题与内容，再检查整篇。多次实际操作中，独立阅读页成功显示全文。普通打开超时后先查看实时标签清单，确认新页是否已经创建，再绑定已有页面。

**手机宽度核验：** 独立阅读页需要检查手机排版时，使用当前浏览器工具明确支持的视口能力临时设置目标宽度；已验证414px宽度下全篇截图及逐板块检查。核验结束恢复原视口或调用该能力的reset，并关闭本次临时预览页。预览宽度与实际PNG尺寸分别记录，滚动条等可能使全篇截图宽度不同。此流程用于手机宽度布局检查，真实手机触摸和发布后效果另行验证。

**操作范围：** 读取当前页面已提供的预览入口，按当前工具允许方式导航。临时预览票据保留在会话内；对外交付使用稳定的编辑链接或用户明确选择的分享方式。手机预览、独立阅读页与真实手机触摸体验分别注明。

## 9. 直接截取正文作为效果证据

**现象：** 图像库导入失败，而当前浏览器已有截图能力；整窗截图还包含编辑器或预览辅助界面。

**已验证：** 使用工具支持的完整页面截图与裁切参数，按当前文章容器的实际边界截取正文，直接保存原始PNG。截图覆盖目标正文范围，并检查文件解码、大小及SHA-256。

**优化：** 优先使用当前工具的截图能力。截图边界从当前阅读页计算，随窗口和版面重新确定。保留当前有效成果和必要证据，过程截图尽量留在会话中，文件收尾按项目规则完成。

## 下一次配色前的快速检查

当前目标和已保存版本 → 文字/图片基线 → 装饰颜色角色 → 纯色/渐变/阴影分类 → 单组件小样 → 同类组件逐项应用 → 保存后回读 → 阅读预览 → 经验合并。
