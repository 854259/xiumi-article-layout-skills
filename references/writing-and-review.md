# 从素材到推文：撰写与审阅

整理日期：2026-10-30。依据为项目现存本人稿、共同修改稿、排版来稿、上届交接培训与栏目策划，以及用户逐次反馈。范例用于提炼方法，姓名、年份、故事、数值、观点及引语各自留在对应来源中。本地来源索引由项目统一记录维护。

## 一、先判断此次要完成哪一阶段

| 用户任务 | 本轮交付与核对重点 |
|---|---|
| 起草 | 当前事实清单、文章主线、完整文字稿及配图位置 |
| 审阅 | 先评价整篇可用程度，再列事实待核对、表达修订和可选精修；按授权决定是否编辑文件 |
| 定向改句 | 围绕选中句段修改，逐段比较前后，保留其余内容及格式 |
| 整篇改稿 | 继承已确认框架，解决本轮明确的问题，核对新增事实和语义变化 |
| 只排版或换配色 | 沿用当前文字版本；疑似错字或事实冲突另记待确认 |

先读取本篇任务记录、当前文稿和最近反馈，再找同栏目参考。用户已限定几句话时，直接处理指定范围；需要完整起草时，按下列流程完成全文。

## 二、准备一张足够用的事实与素材清单

记录：栏目/体裁、受众、文章目的、核心事实、当前人员与职务、时间地点、组织方、实际流程、结果、原话来源、图片、行动入口、署名、版本状态。已有清单直接复用。

- **来源权重：** 当前用户明确要求与确认 → 当前原始材料和已审稿 → 本人已确认写作及修订 → 同栏目范例与交接资料。出现冲突时核对本次事实和具体改动。
- **职责对应：** 本人撰写、共同修改、负责排版、他人来稿和往届参考分别登记。排版来稿用于研究栏目与文图关系，个人写作习惯主要从本人署名稿及明确反馈中提炼。
- **主办角色：** 按实际写学院、资助服务中心、部门和联合举办单位。首次介绍使用准确全称；老师职务和年级采用当前已确认口径。
- **时间状态：** 计划开展、实际开展、完成文字、排版保存、审核与发布分别记录。采访中的规划保持未来时态，活动总结采用已发生事实。
- **材料范围：** 从本篇相关文件中取事实；文件夹、文件修改时间和历史标题用于定位资料，活动年份和日期采用本届证据。
- **来源缺口：** 用简洁“待确认”记录，先完成有依据的段落。直接引语、教师发言、学生感想、技术结论和人物经历逐项对应采访或用户确认。

## 三、选择体裁与写作骨架

### A. 人物访谈：芯青年、国奖与自强之星

**国奖系列已有框架：** 人物速写 → 初心与定位 → 方法与平衡 → 故事与收获 → 展望与寄语 → 按素材安排感恩回望 → 结尾。系列一致性由栏目框架保持，个性由人物的具体经历和原话体现。

1. 从素材中提取一条主线，例如学习方法如何形成、选择如何逐步清晰、受助经历如何转为服务行动。
2. 人物速写选择与主线最相关的身份、成果或经历，把人引入文章。篇幅与同栏目范例和全文相协调；导语的作用是建立辨识度和阅读入口。
3. “初心”解释为何这样选择；“方法”给出实际做法、工具或时间安排；“故事”展开场景、困难、本人行动和变化；“展望”呈现真实计划，寄语采用本人材料。
4. 用“经历或任务—具体行动—结果或体会”组织段落。数字和奖项用来支撑特点，选择与本文有关系的部分。
5. 转述负责提供背景和连接，直接引语保留人物声音。相邻两者各提供有效信息；同一观点集中在最合适的位置表达。
6. 技术经历面向普通学生解释：先说解决什么问题、本人负责什么，再用必要术语说明做法。人物定位采用本人认可且有依据的表述。用户要求淡化专业方向时，改写为成长过程、学习行动或逐渐明确目标的概括。
7. 章节标题写“寄语”时，正文给出对应来源中的建议；资料只有规划时，让标题准确覆盖现有内容。
8. 结尾回扣已展示的人物特点和读者可借鉴的行动；感恩段、末节引语与最终收束分别承担作用。

**自强之星或其他人物稿：** 沿人物成长线组织学习、服务、选择、压力应对和未来方向。四节或五节均可，具体数量由材料决定。温暖来自真实场景、行动和关系，专业成长、服务经历和个人生活按主线分配篇幅。

**多人采访：** 可以按同一个议题串联多人的不同经历，逐段核对引语归属；或采用各自独立小节，确保每人内容与照片对应。

### B. 活动总结与会议报道

**骨架：** 简明导语 → 核心过程 → 成果或代表性案例 → 有来源的反馈 → 活动收束。

1. 导语交代活动目的、时间、主体和对象，用本届真实信息进入正文。
2. 依据当次流程列事件线，再决定详略。筹备、签到、休息、统票等事务简写，核心展示、参与体验、关键成果和有信息量的发言详写。
3. 讲话采用“谈到、分享、鼓励”等与身份和内容相称的动词，提炼已有记录中的具体内容；对应本人讲话照片。仅有照片时先确认人物与环节，写已证实的现场事实；具体发言内容待取得记录或用户确认后补充。
4. 核心活动段落写清“谁做了什么、怎样做、现场有什么特点”。例如按政策情景、知识游戏、案例推理等实际方法归类，随后配相应照片。
5. 优秀名单、排名、评选结果和颁奖方式沿用当前确认。展示照片顺序与现场发生顺序分别维护。
6. 大型总结逐板块检查文字和图片覆盖：开场、答辩/展示、讲话、成果、班级风采、合影按实际内容配置。连续多个对象可集中做滑动，保证逐对象覆盖。
7. 结尾回到具体收获、服务目的或后续安排，篇幅与正文协调。

**资助月实例的适用边界：** 往届报道提供栏目和详略参考；本届报道使用本届主持、班级展示、投票、休息、致辞、结果与合影的真实安排。13班、6个奖项、每人6票属于特定活动信息，下次从新任务记录读取。

### C. 节日与多个活动合辑

采用共用导语、活动分节、自然过渡和共用结尾。每节写出具体动作与体验，例如书写、悬挂、领取、合影等。保持全文主题贯通，主板块篇幅按用户意图分配。

已有教师节合辑的“两板块约1:1”是该篇明确要求；新合辑重新核对侧重点。合影集中展示时，正文保留活动介绍，照片序列承担对象覆盖。用户要求纯图片时采用清洁的图片呈现，滑动提示独立设置。

### D. 预告、招募和志愿推广

**骨架：** 读者需求或兴趣 → 参与价值 → 具体活动/岗位 → 实用信息 → 行动入口。

- 招新可采用已经获得认可的“贴近校园生活的连续问句—欢迎加入—组织理念”，随后说明各部门能做什么、能学到什么。该开头适用于轻快招募，会议报道和人物采访按自身语气组织。
- 志愿推广按活动项目分组，每组交代服务内容、体验、开展频率和参与方式；用具体事项帮助读者选择。
- 预告清楚列出参与对象、日期时间、地点、人数或批次、报名方式、截止、咨询渠道和必要提醒。
- 核对二维码指向、群名称及届别，确保入口与正文活动一致。发布前完成占位日期、编号、路线、集合地点和各处时间的统一检查。
- 结尾给出清晰邀请和入口。活泼程度按场景与用户要求调整；正式名称、操作信息保持准确。

### E. 政策与服务信息

从学生实际疑问切入，例如申请条件、材料流程、办理渠道或志愿服务信息。按“问题—适用对象—解决办法/资料—办理或反馈入口”组织。涉及政策原文时使用当前权威来源核验，区分政策内容、编辑解释与征集建议。具体截止、金额、资格和联系方式逐项校对。

征集稿把“征集什么、如何提交、何时截止、向谁咨询”拆成清楚的信息单元。用户只要求整理或排版现稿时，事实疑点记入当前工作记录，并沿用该任务的核验范围。

## 四、共同语言风格

1. **正式、温暖、贴近学生。** 用熟悉的词、具体动词和清楚的因果写人写事。抒情依托真实经历，篇幅服从信息和阅读节奏。
2. **标题有识别信息。** 一级标题沿用栏目样式，如“栏目 | 本篇主题”；人物题目可用“姓名——主题短句”。小标题保持同篇句式、标点和层级协调，准确概括该节内容。
3. **主语和身份准确。** 组织名使用“资助服务中心”等已确认全称；人物介绍采用当前职务；贡献和职责对应实际承担者。
4. **把意义落到事实。** 用实际人数、行为、成果和反馈支撑效果判断。教师发言、活动影响与个人贡献采用与证据相称的表述。
5. **段落逐步推进。** 每段围绕一个中心，先给内容，再作必要概括。长句分清主语、动作与结果；同一结论选择最合适的位置保留。
6. **新写规则与进度采用正向行动表达。** 写“先核对姓名”“使用真实缩进”“保持原话含义”等可执行要求。原始引语按忠实性处理，润色范围沿用用户授权。

范例中的对仗、排比、意象和表情是可选手法。用户最新的简洁、正向、专业标签取舍和本篇语气要求决定最终文字。

## 五、审阅与定向修订

按顺序检查：

1. **硬信息：** 姓名、班级/年级、职务、年份、时间地点、活动组织方、流程、名单、结果、奖项、二维码与联系方式。
2. **内容完整：** 每个标题有相应内容，故事有具体过程，方法有实际做法，结论有来源。
3. **结构与详略：** 主题明确，主板块完整，重点充分，事务衔接简洁，导语与结尾长度合适。
4. **语言：** 搭配、指代、语序、标点、同词重复、技术名词密度、转述与引语重复、结尾重复收束。
5. **改动范围：** 将每一修改对应到用户要求。用户指定段落时，核对目标段落及相邻衔接；全文改稿核对整篇结构与事实变化。

审阅输出先说文字稿当前可用程度，再给最关键的具体建议。清楚区分“已修改并回读”“建议修改”“待核对来源”和“可选精修”。原始采访事实的核验、文字审阅、Word版式与公众号手机阅读分别记录。

若编辑DOCX，保留原稿并按项目版本规则留存；局部修改检查正文与格式的变化范围。Word工作标记如“采访结尾”、配图位置和取图附件用于交接，最终发布画面按实际编辑方案展示。

## 六、从文字稿交接到排版

- 每个主板块列出需要的照片，文档中放到相应位置，同时保留原图及来源清单。
- 图片匹配人物、班级和内容，按当前指令决定顺序、滑动和图注。封面、生活照、活动照、合影分别承担合适作用。
- 署名区沿用已确认的栏目组件，按实际贡献填写文字、图片、排版及审核人员；统一来源形式与分隔样式。
- 正文稿与在线稿各记版本；改动或同步按本轮范围完成。交付时给出当前文稿/编辑链接、实际检查情况和剩余具体待办。

## 七、本次样本覆盖与后续使用

本次全文分析范围为资服工作目录可定位的推文正文：部员阶段8题9份DOCX，部长阶段9题12份DOCX，交接ZIP内6篇推文；另读取《推文撰写及排版》和国奖系列策划2份。现存重复副本、原稿/修改稿及与交接重叠的文稿分别登记。纯采访提纲、逐字稿、简历、学生班级提交材料和个人申报材料作为上游资料按需使用。

对仅在任务记录中出现、原稿保留在其他路径的审阅结论，本次沿用其明确记录的判断。已读样本表现出的写法属于参考；实际新稿继续以当次用户要求、当前素材和栏目规则决定。
