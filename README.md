# 推文撰写与秀米排版 Skills

从素材整理、栏目撰写、审阅改稿，到秀米逐段排版、配图配色、横向滑动、保存核验与经验迭代的一套中文工作方法。

适用于公众号人物访谈、活动总结、节日合辑、预告招募和政策服务文章。平台操作以当前可见界面和所用工具文档为准；其他编辑平台可以复用适用的文字、文图核对及验证原则。

## 入口

- [SKILL.md](SKILL.md)：任务分流和完整工作流程。
- [撰写与审阅](references/writing-and-review.md)：五类体裁、语言风格、事实核对和定向改稿。
- [秀米操作](references/ui-workflow.md)：选模板、另存、逐段编辑、真实缩进、加滑动页、逐页换图与双向核验。
- [配色与恢复](references/color-and-recovery.md)：连接恢复、组件层级、纯色与渐变、标题阴影、保存及阅读预览案例。
- [经验迭代](references/learning-loop.md)：记录新问题、验证解法、合并重复经验和公开贡献。

## 使用

将仓库内容放入个人 skills 目录下的 `xiumi-article-layout` 文件夹，确保 `SKILL.md`、`agents/` 和 `references/` 层级保持完整；已有同名技能先检查差异并保存当前版本。安装位置采用所用AI工具的实际配置。

支持显式调用 `$xiumi-article-layout`，并在支持技能自动发现的环境中保留自然语言调用。示例：

- “根据采访素材起草一篇国奖人物推文，沿用本栏目框架。”
- “审阅这篇活动总结，先看事实和流程，再精简文字。”
- “继续排这篇推文，把滑动加到13页，按给定顺序替换照片。”
- “只调整装饰配色，保留文字、图片、顺序和其他格式。”

格式基线来自实际使用需求：正文15px、字距1px、行距1.8倍、真实首行缩进、左右20px。当前用户的具体要求优先；特殊卡片按容器结构调整。

所有协作规则公开可读。使用者保有对自己的资料、账号和提交动作的选择权；AI执行外部提交时依据当前用户授权。素材原文、人物照片、私聊、账号信息与临时预览凭证由使用者本地保管，公开案例采用脱敏的通用描述。

本技能提供可执行的文字工作流。实际工具能力、页面状态和结果验证随每次任务检查。
